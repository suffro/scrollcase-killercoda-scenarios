# Install and initialize

First install the Scrollcase CLI:

`npm install --global scrollcase`

Then initialize the project, its runnable example, and the project-local toolchain:

`scrollcase init --install-toolchain`

Optional consumer packages are skipped in this demo. Their Node and Python templates are still
created under `consumer-templates/`.

[Installation documentation](https://scrollcase.dev/getting-started/installation) ·
[`init` reference](https://scrollcase.dev/reference/cli#init)

**Please wait until setup is complete.**
