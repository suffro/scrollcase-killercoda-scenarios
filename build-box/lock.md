# Lock and commit

Resolve the example's Pixi manifest into its reproducible lock:

`scrollcase lock example-box/linux-x86_64-cpu`

The generated project and lock are then committed. A box records its source commit, so Scrollcase
does not build from an uncommitted tree by default.

[`lock` reference](https://scrollcase.dev/reference/cli#lock)

**Please wait until it is complete.**
