# Build a Scrollcase box

This scenario starts with an empty Git repository in a disposable Linux environment.

You will:

- install the Scrollcase CLI;
- initialize a project and its local build toolchain;
- lock and commit the example environment;
- create a signing key and build the box;
- verify the signed result and run its self-test.

The example is deliberately small, but it exercises the complete build pipeline.

Click **START** to continue.
