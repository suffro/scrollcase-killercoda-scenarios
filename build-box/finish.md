# Done

You initialized a Scrollcase project, locked its environment, built and signed a box, and verified
the result with the box's own Python interpreter.

Optional next steps:

- run it with [`scrollcase run`](https://scrollcase.dev/reference/cli#run);
- try the generated Node or Python templates with the
  [consumer APIs](https://scrollcase.dev/reference/api);
- create your own input with [`scrollcase new scroll`](https://scrollcase.dev/reference/cli#new);
- inspect the machine with [`scrollcase doctor`](https://scrollcase.dev/reference/cli#doctor);
- review dependency licences with [`scrollcase audit`](https://scrollcase.dev/reference/cli#audit).

Learn more in the complete [Quickstart](https://scrollcase.dev/getting-started/quickstart) or on
[GitHub](https://github.com/suffro/scrollcase).
